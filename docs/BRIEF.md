# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：皮肤黑色素瘤患者与照护者双主体；覆盖自查发现、确诊与分期（SLNB）、手术、靶向/免疫治疗、双轨随访（皮肤+影像）、复发监测与照护决策全程；支持代记与私密内容分级

场景：患者与照护者整理自查记录（部位/照片/变化自述）、病理与分子（BRAF/NRAS）、前哨淋巴结与分期、影像随访、靶向/免疫治疗周期与不良反应、皮肤科复查节奏，准备复诊问题并回顾医生确认后的记录

核心流程：
1. 选择本地资料目录并登记皮损自查记录、病理分子、手术与分期、治疗与影像材料
2. 核对分子三态（未检测不等于阴性）、分期引用、免疫相关不良反应与随访双轨记录
3. 查看自查照片与指标趋势，标记症状与待办，生成复诊摘要与问题清单
4. 照护者以代记身份记录皮损变化与照护线索，私密内容分级管理，并把明确任务交给 Desktop 原生 Agent 会话

完成结果：患者与照护者确认的资料和随访时间轴、可追溯的皮损变化与指标趋势、治疗与不良反应记录、复诊摘要均保存在明确选择的本机资料目录中；私密内容按 visibility 分级且三处出口过滤

初始布局选择：business-first
