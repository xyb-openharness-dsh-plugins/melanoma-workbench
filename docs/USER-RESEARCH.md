## 三条核心发现
1. **自查是主动形态（实证）**：西班牙队列 53% 自检发现；英国 59 名自检者叙述"这跟我那颗痣不一样"；中国广西定性 12/16 曾误判为黑线/鸡眼/普通痣 → **产品入口必须在确诊之前**（自查档案独立一级线的证据基础）。
2. **中国肢端语境成立**：卫健委指南肢端约 50%、CSCO 调研 51%/足底 48%；**56% 初诊即 III–IV 期**；西京 118 例误诊中位病程 **54 个月** → 足底/趾缝/甲下自查 + "鸡眼/灰指甲/甲下血肿"翻译卡是刚需。
3. **早期 FCR 同样高（75% 超阈值）且不得承诺消除**：MELACARE RCT 改善 QoL/患者激活但**未显著降低 FCR** → 文案红线：不写"缓解/消除复发恐惧"，只提供记录与问题清单。
