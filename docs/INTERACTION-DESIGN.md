## 二、CRUD 双通道矩阵（按实体填全：AI 默认列 + 手工收敛列 + 红线列）

| 实体 | AI 协助（默认） | 手工（收敛入口） | 红线 |
| --- | --- | --- | --- |
| 皮损记录（lesion） | 对话「今天看到一块斑」→ 候选（部位/日期/尺寸/自述） | 「＋ 记录一颗痣 / 一块斑」5 字段（部位/日期/最大径/颜色形状/自述） | 只记录，不判良恶性；无 benign/malignant 列；变化只并列（K1/K2） |
| 照片引用（photo） | 照片日期/尺寸文字识别→候选 | 皮损详情 `⋯ → 补一张照片` 4 字段 | 照片仅本机保存（接入后）；不做图像判读；足底/甲下默认仅本人可见 |
| 自查场次（acral session） | 肢端引导对话→候选打卡 | 引导页逐步记录（节奏由用户设定，默认每月；不鼓励每日） | 不写「观察即可」；红线只列信号（出血/不愈/变大/颜色不均） |
| ABCDE 说明 | —（只做名词解释，不 AI 判定） | 说明卡静态展示 | 不出现「符合几条 = 风险」；解释不是判断 |
| 分期（stage） | 报告解析→候选（原文 + 日期） | 分期档案版本链（医生记录新增一条） | 只引用医生 / 病理原文；无 TNM→分期推导；不解释严重不严重（K3） |
| 前哨淋巴结（SLNB） | 病理报告解析→候选 | 三态登记（未做 / 结果原文 / 未记录） | 「未做」是明确状态 ≠「没记录」；不做推荐（K3） |
| 分子检测（BRAF/NRAS/TERT） | 报告解析→候选（marker/status/original） | 「＋ 登记一次检测」3 字段 | 三态；未检测 ≠ 阴性；不写具体比例（K4） |
| 治疗周期（systemic） | 医嘱拍照→候选周期 | 「＋ 登记一次治疗」3 字段（日期/状态/原因原话） | 只记录；不评疗效、不判进展；剂量变更留痕 |
| IO 事件（irae） | 对话「起疹子/腹泻」→候选（轨道/日期/原话/分级） | 「＋ 记一次 IO / 靶向反应」4 字段；皮疹页另有 4 字段 | 四轨独立、永不加总；严重度只抄院方原文；无 causality 列（K5） |
| 皮疹照片 + 自评 | 照片→候选；自评枚举 | 「＋ 记一次皮疹」4 字段（部位/日期/是否发热/自述） | 「皮疹是药还是病」只列问题不归因；可延迟至停药后（K5） |
| 双轨节点（followup） | 复诊记录解析→候选 | 皮肤复查 / 影像复查各 4 字段 | 两轨各自节奏；不生成「下次总复查」；不暗示可以减少检查（K6） |
| 隐私偏好 | —（本机设置） | 复查准备页逐项设置（范围/内衣/医生性别/陪同/屏风） | 只存本机、默认仅患者可见；不改变医院流程 |
| 防晒 / 暴露史 | 对话→候选（事实） | 「＋ 记一次户外 / 防晒」2 字段 | 只做事实提醒，不做命令式；不写「涂 SPF50 就不会」；自责不是道德失败（K6） |
| 食量 / 疲劳 | 对话→候选 | 各 2 字段（日期/自述） | 不给食谱、热量处方或康复处方 |
| FCR / 身体意象 / 亲密 | 对话代记→候选（默认 private） | 「＋ 记一条感受」4 字段（记录人/日期/0–10/原话）；身体感受 2 字段 | 双源并列不平均；不承诺恐惧会消失；private 默认三处过滤 |
| 材料 / 疑问 | 清单为要素，不 AI 生成答案 | 材料三态勾选；「＋ 添加疑问」1 字段；勾选=已问 | 只整理不回答；两区导出 private 过滤 |
| 候选 / 文档 | MinerU 解析→候选（来源页 + 状态） | 候选页逐项确认入库 / 拒收；「＋ 导入一份资料」3 字段 | 候选未确认不进事实层；失败不产候选；原件保留 |
| 试验线索 | —（只陈列，不推荐） | 收藏 / 取消收藏 | 「登记状态，未核实」常驻；不判入组资格 |
| 更正 / 删除 | 对话改数→候选 diff | `⋯ → 改这一条`（登记新版本） | 删除不存在；更正 = 新增版本，旧记录保留（无「不可恢复」） |

**收敛校验**：每页显式编辑入口 ≤1（X3 实测：32 视图 × 2 档案，0 违规）；表单最大 5 字段（全部 ≤6）；
10 条一级线每页右上均有同一种「AI 协助」入口（填草稿不代发）；候选确认/拒收后按钮消失，避免重复操作。

## 三、原型落地要求（已实现，自验数字见 §四）

- **看板双主体 8 入口**：本人 4（记录皮损 / 分期分子 / 记 IO 反应 / 下次双轨）+ 照护者 4（代记变化 / 背部盲区代检 / 陪诊隐私 / 复诊材料）。
- **13 枚场景 chip**（S01–S13 一一对应）；`data-scene` 与 `SCENES` 同源。
- **AI 协助**：`aiPromptWithCtx(page)` 生成「场景提示词 + 本页病情上下文」→ `postMessage({type:'mel:agent-draft', prompt})`；
  外壳 client 监听 `mel:agent-draft`，无会话时先 `ensureSession` 再填草稿；**不自动发送**。
- **候选核对闭环**：候选卡 → 确认入库 / 逐项修改 / 拒收；解析候选页同样 accept / reject 三态。
- **一图秀**：数值线 4 条（体重 / ALT / TSH / 同模态皮损最大径）+ 分类节点 5 个（就诊 / 活检 / 手术 / 皮肤复查 / 1 级皮疹）；
  `smoothPath` 用 **Fritsch–Carlson 单调三次**；分类节点只画点不连线；`.chart .line` 的 computed fill = `none`。
- **肢端翻译卡**：足底 / 趾缝 / 甲下自查语境 + 鸡眼 / 灰指甲 / 甲下血肿 / 摩擦淤青对照；只解释名词，不是诊断（K1）。
- **照片对比**：无真实图片，用部位色块 + 日期 + 尺寸 + 自述；页内常驻「照片仅本机保存（接入后）」。
- **窄宽**：按 RESPONSIVE-RULES 六条（卡内纵向、grid minmax(0,1fr)、min-width:0、scroll-hint、短 token nowrap、断点 1180/900/600）；
  表格内部横向滚动而不是压成竖排单字。
