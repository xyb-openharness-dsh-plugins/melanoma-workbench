# 患者流程（PATIENT-FLOW）· 三流骨架（M1 填实）

流一：自查发现（家族首次形态）——洗澡时发现背上痣变了；ABCDE 记不全 → 皮损自查档案（部位/照片/自述变化）+ ABCDE 说明卡 → 预约皮肤科。产物：自查记录 + 问题清单。
流二：确诊与分期——活检病理、前哨淋巴结、BRAF 结果 → 分期档案（引用）+ 分子三态 → 与医生讨论方案。产物：分期与分子摘要。
流三：治疗与双轨随访——免疫/靶向治疗的皮疹腹泻；皮肤科 3 月复查与影像 6 月复查不同频 → IO 不良反应轨道 + 双轨随访日历 + 影像并列。产物：复诊摘要（private 过滤）+ 双轨节奏视图。
反推原则同家族；与 cervical 重名率 ≤70% 实测。
